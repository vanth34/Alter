# Разрешения

Alter запрашивает небольшой набор разрешений, и все они связаны с работой с
APK-файлами, сохранением дампов и управлением бэкапами регулярок. Приложение не собирает
аналитику и никуда не отправляет ваши данные.

- **Чтение общего хранилища** (`READ_EXTERNAL_STORAGE`): читать выбранные
  APK-файлы и импортировать бэкапы коллекций регулярок.
- **Управление всеми файлами** (`MANAGE_EXTERNAL_STORAGE`): доступ к APK в любом
  месте устройства и сохранение дампов в `/sdcard/Alter`.
- **Запись в общее хранилище** (`WRITE_EXTERNAL_STORAGE`): сохранять дампы,
  пропатченные APK, сгенерированные файлы и бэкапы регулярок.
- **Список установленных приложений** (`QUERY_ALL_PACKAGES`): показывать
  установленные приложения как цели для дамперов.
- **Установка пакетов** (`REQUEST_INSTALL_PACKAGES`): ставить обновления и
  32-битное приложение-помощник.
- **Вибрация** (`VIBRATE`): тактильная отдача при действиях в интерфейсе.
- **Интернет** (`INTERNET`): проверять обновления и скачивать свежий релиз.
- **Состояние сети** (`ACCESS_NETWORK_STATE`): определять наличие сети перед
  сетевыми операциями.

Root при запуске не запрашивается. Доступ у менеджера root просит только
**Root dump DEX** и только когда вы его открываете.

## Примечания

- **Доступ к хранилищу на Android 11+.** Поскольку Alter патчит произвольные
  APK-файлы, выбранные пользователем, он использует доступ ко «всем файлам»
  (`MANAGE_EXTERNAL_STORAGE`). Выдать его можно в
  **Настройки → Приложения → Alter → Разрешения**.
- **`READ_/WRITE_EXTERNAL_STORAGE`**: устаревшие разрешения для хранилища,
  актуальны в основном для Android 10 и ниже.
- Интернет Alter использует только для проверки обновлений и скачивания, больше
  ни для чего.
