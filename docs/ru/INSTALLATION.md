# Установка

## Требования

- **Android 8.0 (API 26)** или новее, ARM-устройство (`arm64-v8a` или `armeabi-v7a`)
- **Root не нужен** (он используется только в Root dump DEX)
- Разрешение на доступ к хранилищу (выдаётся при первом использовании, см.
  [PERMISSIONS.md](PERMISSIONS.md))

## Установка APK

1. Откройте [последний релиз](https://github.com/vanth34/Alter/releases/latest).
2. Скачайте `app-release.apk`.
3. Откройте скачанный файл. При запросе разрешите браузеру или файловому
   менеджеру установку неизвестных приложений:
   **Настройки → Приложения → Специальный доступ → Установка неизвестных приложений**.
4. Подтвердите установку.

## Обновление

Alter умеет проверять обновления внутри приложения. Также можно в любой момент
зайти на страницу Releases или воспользоваться постоянной ссылкой выше, чтобы
скачать свежую сборку.

## Удаление

**Настройки → Приложения → Alter → Удалить.** Ваши экспортированные бэкапы
регулярок (файлы `.zip`, сохранённые в хранилище) остаются на месте и при удалении
приложения не стираются.
