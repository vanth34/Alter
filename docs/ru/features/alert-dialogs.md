# Генератор Alert-диалогов

Генерируйте готовый **Smali**-код alert-диалогов, не набирая его вручную.
Выберите стиль, заполните короткую форму, посмотрите превью и скопируйте
результат в свой проект.

## Стили

Стиль выбирается вверху экрана. У каждого свой внешний вид, а превью показывает
диалог ровно таким, каким его увидят пользователи целевого приложения.

## Поля

Диалог собирается из простой формы. Типичные поля:

- **Dialog Title**: заголовок.
- **Dialog Message**: текст сообщения.
- **Negative Button Text**: текст отрицательной кнопки.
- **Positive Button Text**: текст положительной кнопки.
- **Positive Button Link**: ссылка, открываемая по нажатию положительной кнопки.
- **Secret cryptKey**: ключ, используемый встроенной защитой.

У некоторых стилей есть свои поля, например цвет акцента или дата истечения.
Форма показывает их сама, когда вы выбираете такой стиль.

Кнопка **Save** сохраняет диалог, **View** показывает превью.

## Результат

**Save** записывает результат в `/sdcard/Alter/<Стиль>/`, у каждого стиля своя
папка:

- `classes.dex`: собранный диалог. Добавьте его в целевой APK следующим
  `classesN.dex`.
- `hook.smali`: строка, которая показывает диалог. Вставьте её в `onCreate`,
  `onResume` или `onStart` активити, где должен появиться диалог.

## Защита от подделки

Сгенерированные диалоги содержат встроенную логику защиты, поэтому их нельзя
незаметно обойти правкой `SharedPreferences` приложения-носителя. Диалог
проверяет собственное сохранённое состояние (по вашему *cryptKey*), прежде чем
решить, был ли он уже показан, что не даёт простой правкой «пометить как
просмотренный» пропустить его.

> Держите `cryptKey` неизменным для конкретного диалога, он связывает
> сгенерированный код с его сохранённым состоянием.
