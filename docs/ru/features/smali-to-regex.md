# Smali в Regex

Писать регулярку под блок smali вручную долго, и она легко ломается: регистры и метки меняются при каждой пересборке приложения. **Smali in Regex** превращает фрагмент в паттерн, который переживает такие изменения.

## Как пользоваться

1. Откройте **Smali in Regex** на вкладке Home.
2. Вставьте фрагмент smali кнопкой **Вставить из буфера** (или введите вручную).
3. Нажмите **Конвертировать**.
4. Нажмите **Копировать результат** и сохраните паттерн в [менеджере регулярок](regex-manager.md).

## Что делает конвертер

- **Экранирует** спецсимволы регулярок: `[ ] ( ) { } \ $ ^ | + * ? . "`.
- **Регистры** вроде `v0` или `p1` превращаются в `[vp]\d+`.
- **Отступ** из четырёх пробелов превращается в `\s{4}`.
- **Переносы строк** превращаются в `\n`, так что весь фрагмент становится одним паттерном.
- **Метки** вроде `:cond_1a` и `:goto_3` превращаются в `:cond_[A-Za-z0-9]+` и `:goto_[A-Za-z0-9]+`.

## Пример

```smali
    const/4 v0, 0x1
    if-eqz p1, :cond_0
```

превращается в

```
\s{4}const/4 [vp]\d+, 0x1\n\s{4}if-eqz [vp]\d+, :cond_[A-Za-z0-9]+
```
