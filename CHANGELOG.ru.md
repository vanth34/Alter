# История изменений

Здесь фиксируются заметные изменения в Alter. Проект использует версии на основе
даты (`ГГГГ.ММ.ДД`).

**Alter 2026.11.02 Azoth**

- Новый инструмент Rootless dump DEX: извлечение DEX из защищённых приложений без root
- Выбор цели из установленных приложений или из файла .apk / .apks
- Глубокий анпакинг с восстановлением тел методов, в том числе на Android 12+
- Параметры анпакинга: Hook-дамп, Автовызов, проверка DEX, дамп двух архитектур
- Поддержка 32-битных приложений через 32-битный помощник
- Новый инструмент Root dump DEX для устройств с root (arm64)
- Режим God Dump для поиска скрытых и динамически загружаемых DEX
- Список приложений с поиском и фильтрами системных приложений и XP-модулей
- Новая функция Smali in Regex
- il2cpp dumper полностью переписан: дамп создаётся без запуска игры с поддержкой метаданных il2cpp версий v24–v31
- Опциональное сохранение скриптов для IDA Pro, Ghidra, Binary Ninja и radare2 рядом с dump.cs
- Режим «Инжект» для создания пропатченной копии APK со встроенным дампером теперь автоматически извлекает файлы в папку Alter, Document Provider или Root больше не требуются
- Режим «Инжект» поддерживает сплит-APK (.apks, .xapk, .apkm) и собирает их в один файл
- Новый дизайн всех экранов в стиле Material 3
- Светлая, тёмная или системная тема
- Динамические цвета из системной палитры (Android 12+)
- Нижняя панель навигации Home / Regex: плавающая или классическая
- Эффект жидкого стекла (полный эффект на Android 13+)
- Настройка качества стекла с автоматическим подбором под устройство
- Плавные анимации переходов между экранами и вкладками
- Корректное отображение под системными панелями и вырезами экрана
- Приветственное обучение при первом запуске
- Значительно ускорена работа интерфейса и отклик приложения
- Быстрая и плавная прокрутка коллекции регулярных выражений
- Понятные сообщения об ошибках при дампе
- Выбор папки для сохранения результатов
- Подробный отчёт об ошибке с кнопкой копирования лога
- Повышена стабильность работы на Android 8–16
- Встроенное окно обновления со списком изменений
- Загрузка и установка обновления прямо из приложения
- Возможность отложить или пропустить версию обновления
- Удалён инструмент защиты строк APK (LSParanoid)
